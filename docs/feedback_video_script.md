# Project FORESIGHT - Feedback Video Script

## Recording setup

- Target duration: 60-90 seconds
- Record yourself speaking, with the app or project report visible in the background if possible.

## Script

> Hello, I am Shaik Muzamil, and this is my reflection on Project FORESIGHT.

> The project challenged me to connect a modern frontend with a practical data and analytics workflow. I learned how to structure a FastAPI backend into focused routers, persist retail transaction data through SQLAlchemy, and make dashboard metrics, risk recommendations, and forecasts come from the same stored dataset.

> One key challenge was making the platform honest and reliable rather than only visually impressive. I addressed that by replacing fixed API responses with real data-driven routes, making file upload perform actual ingestion, applying forecast limits, and moving database configuration into environment variables.

> I also strengthened my understanding of inventory concepts such as lead-time demand, safety stock, reorder points, and stockout risk. The most valuable takeaway is that a forecasting model only helps when its results are connected to a clear operational action, such as a prioritized replenishment recommendation.

> In the future, I would add authentication, scheduled retraining, supplier-specific constraints, and richer scenario planning. Thank you for reviewing Project FORESIGHT.
